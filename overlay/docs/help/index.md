# baf-dsh

**baf-dsh** 是基于 DeepSeek Harness 的桌面客户端：用本机窗口运行 `dsh web`，完成对话、设置与工作区协作。

## 你能做什么

| 能力 | 说明 |
|------|------|
| 对话与工具 | 与上游 Web GUI 相同的会话、工具与工作区能力 |
| 桌面壳 | 启动 splash、系统标题栏、托盘与关闭偏好 |
| IDE 快捷打开 | 若本机有 VS Code / Cursor CLI，可在标题栏一键打开当前工作区 |
| 版本与更新 | 设置页查看 `baf-dsh` / 上游 / 插件版本，并检查更新 |

## 三步开始

1. [安装与启动](install.md) — 安装包要求与首次启动
2. [快速上手](getting-started.md) — 配置 API Key、打开工作区、开始对话
3. 卡住时查 [常见问题](faq.md)

本手册可在主界面左下角「帮助」中打开，也可点击面板顶部「在浏览器中打开」。

## 环境要求（摘要）

- Windows x64
- Node.js `^22.19.0 || >=24.0.0`（安装器可检测并随装）
- DeepSeek API Key（在 Web「设置」中配置）
