# 快速上手

## 1. 配置 API Key

打开主界面 **设置**，填入 DeepSeek API Key（及可选 Base URL）。密钥写入本机用户配置，不会随安装包分发。

## 2. 选择工作区

在侧栏或工作区入口选择本地项目目录。对话中的文件与终端工具默认相对该目录。

## 3. 开始对话

在输入框描述任务。空状态标题为「探索未至之境，拉启智能篇章」。

## 4. 可选：在 IDE 中打开

若本机 PATH（或常见安装路径）中有 `code` / `cursor` CLI，标题栏会出现对应图标；点击后以当前工作区路径打开该 IDE。

## 5. 关闭行为

关闭窗口时可选择最小化到托盘或退出。可在「设置 → 通用设置」末尾修改默认行为，并与「下次不再询问」共用偏好文件。
