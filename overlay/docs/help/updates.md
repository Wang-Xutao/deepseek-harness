# 版本与更新

baf-dsh 的版本分**三层**，检查更新、查看版本都在 **设置 → 版本与更新**（与指令 `/baf-version` 同源）。

## 三层版本（与设置页一致）

1. **BAF DSH DESKTOP** — 桌面应用本身（桌面壳、安装器、帮助站），独立版本号。
2. **DeepSeek Harness** — 上游核心（会话、工具、Web GUI 主体）。
3. **BAF 插件包** — 7 个工作流插件包（core / workflow / openspec / standard / quality / guard / scaffold），各自独立的 semver 版本号，**随应用一起安装、一起更新**，无需单独管理。每包的详细介绍见 [BAF 插件包](baf-packages.md)。

## 检查更新

在 **设置 → 版本与更新** 点 **「检查更新」**（仅桌面应用可用），结果显示在**按钮正下方**：

- **有新版本**：更新摘要、**当前版本**与**最新可升级版本**并排列出，点「更新」开始升级。
- **已是最新**：同样列出当前版本与最新版本号。
- **检查失败**：红字只给出**故障码 + 一句话**（如「检查更新失败：故障码 U-01 · 更新服务尚未就绪（详见 帮助文档→版本与更新）」）。技术细节不再刷屏，完整解释见下表。

## 更新故障码

| 故障码 | 一句话 | 技术原因（发生在了什么） | 处理指引 |
| --- | --- | --- | --- |
| **U-01** | 更新服务尚未就绪 | 更新来自 GitLab Releases 的 `baf-channel-stable` 通道（项目 `ai/workflow/baf-dsh`）；仓库尚未发布该 Release（HTTP 404）。发布侧需在 baf 分支打 `baf-dsh-v*` 标签并完成发版流水线。 | 稍后再试即可；若你是发布侧，请先完成通道发版。 |
| **U-02** | 网络连接失败 | 访问 GitLab（`gitlab.sinc.lan` 的 Release API / 产物直链下载）在网络层失败（DNS、代理、断网、防火墙）。 | 检查网络或代理后重试；内网环境需放行 `gitlab.sinc.lan` 与产物所在的存储域名。 |
| **U-03** | 更新通道数据异常 | 通道能访问，但内容不对：非 404 的 HTTP 错误（限流 403/5xx 等）、Release 缺少 `manifest.json`、manifest 解析失败。 | 稍后再试；持续出现说明通道发布物损坏，需发布侧补齐 manifest。 |
| **U-04** | 更新包安全校验未通过 | 更新包未通过安全校验：manifest 缺签名、签名 keyId 未注册、使用测试签名 key、签名不匹配，或安装包 sha256 校验失败。 | **不要**重试绕过；这是安全机制在拦截被篡改或不完整的更新，请联系发布侧核实。 |

## 应用怎么更新

1. **启动时后台检查**：splash 阶段即检查更新，主界面就绪后如有新版本会弹窗让你选 **立即更新 / 稍后**。
2. **小改动走热替换**，无需重装；**大改动下载 Setup 安装包覆盖安装**（数据目录 `%USERPROFILE%\.dsh` 与偏好 `%APPDATA%\baf-dsh\` 都会保留）。
3. **更新点（更新内容）**显示在检查结果里：本版本带来了什么、改了什么，按发布说明**分段分点**书写，与 BAF DSH DESKTOP 的发布说明保持一致。

## BAF 插件包的热升级

BAF 插件包除「随应用一起安装、一起更新」外，还支持**热升级**：

- 会话里执行 **`/baf-update`**：无需重启应用，检查并把 BAF 插件包升到新版本。
- 会话里执行 **`/baf-update-rollback`**：把热升级回滚到上一版。
- 设置 → 推荐插件 里的**外部插件**（如飞书）走同一热更新通道，也可在设置页直接安装、更新（详见 [推荐插件](featured-plugins.md)）。

## 常见疑问

**问：设置页提示「检查更新与升级仅在 baf-dsh 桌面应用中可用」？**
答：设置页的检查更新按钮只在桌面应用里可用；web 端可用 `/baf-version` 查看版本，插件包热升级 `/baf-update` 两端都可用。

**问：自动更新会自己装吗？**
答：应用更新弹窗由你选择立即或稍后；BAF 插件包热升级需你执行 `/baf-update`；推荐插件里的外部插件可按插件打开「自动更新」开关（见 [推荐插件](featured-plugins.md)）。
